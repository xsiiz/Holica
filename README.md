# Holica AI - Uncensored Chat, Image & Video Web Studio

A full-stack, unrestricted AI web application powered by Google Colab (NVIDIA T4 GPU) featuring:
- **AI Chat**: Uncensored LLM (Dolphin Mistral 7B) with streaming response.
- **AI Image Generation**: Uncensored Stable Diffusion (CyberRealistic / SD 1.5) with Safety Filter disabled.
- **AI Video Generation**: Text-to-Video & Image-to-Video with AnimateDiff v3.
- **Remote Cloudflare Tunnel**: Free, secure HTTPS connection directly from Google Colab.
